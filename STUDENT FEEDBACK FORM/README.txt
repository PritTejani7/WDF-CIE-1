SIMPLE STUDENT FEEDBACK DASHBOARD

Files:
1. index.html
2. style.css
3. script.js

How to run:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in a browser.
3. Enter names and select all three ratings.
4. Press Submit Feedback to see the average, percentage, classification and recommendation.

Test case 1:
Teaching = 5, Practical = 5, Content = 4
Expected average = 4.67
Expected percentage = 93.33%
Expected classification = Excellent

Test case 2:
Leave Student Name blank or leave one rating unselected.
Expected result = Error messages appear and the form is not processed.
